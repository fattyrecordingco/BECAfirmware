# BECA Installers

Download app **0.2.0**, including firmware **1.1.0**, from the [official release](https://github.com/fattyrecordingco/BECAfirmware/releases/tag/setup-v0.2.0). These links download the current installers directly:

- Windows x64: [setup EXE](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/BECA_0.2.0_x64-setup.exe) · [MSI](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/BECA_0.2.0_x64_en-US.msi)
- macOS: [Apple Silicon DMG](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/BECA_0.2.0_aarch64.dmg) · [Intel DMG](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/BECA_0.2.0_x64.dmg)
- Linux x64: [AppImage](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/BECA_0.2.0_amd64.AppImage) · [DEB](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/BECA_0.2.0_amd64.deb)

Separate assets: [firmware 1.1.0](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/beca-1.1.0-merged.bin) · [firmware manifest](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/firmware-manifest.json) · [SHA256SUMS](https://github.com/fattyrecordingco/BECAfirmware/releases/download/setup-v0.2.0/SHA256SUMS).

The 0.1.7 binaries in the platform folders are historical. Current installers are hosted in Releases; the release workflow does not commit binaries to this folder.

Before first launch, read:
- [docs/user/READ_BEFORE_FIRST_LAUNCH.md](../docs/user/READ_BEFORE_FIRST_LAUNCH.md)

The Windows installer is unsigned and Mac builds are not notarized; read the release notes and verify the checksum before installation.

For first installation, open Setup and choose **Included 1.1.0 · works offline**. No separate firmware download is required.
