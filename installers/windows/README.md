# Windows Installer

Download `BECA_0.2.0_x64-setup.exe` from the [0.2.0 release](https://github.com/fattyrecordingco/BECAfirmware/releases/tag/setup-v0.2.0). The MSI is for managed installation. The 0.1.7 binaries in this folder are historical; new installers and SHA256SUMS are release assets.

Read first:
- [Read Before First Launch](../../docs/user/READ_BEFORE_FIRST_LAUNCH.md)

Restart after USB driver installation if requested by its installer. See the manual for the one-time virtual MIDI cable setup and unsigned-prerelease limitations.
