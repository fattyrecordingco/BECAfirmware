# BECA Installers (All OS)

**App 0.2.0 with firmware 1.1.0 is available for Windows, macOS and Linux.** Choose your computer in the [download table](README.md#download-beca-020), or open the [official release](https://github.com/fattyrecordingco/BECAfirmware/releases/tag/setup-v0.2.0) for all installers, firmware and checksums.

Read the [first-launch guide](docs/user/READ_BEFORE_FIRST_LAUNCH.md). Every installer includes firmware 1.1.0; in Setup choose **Included 1.1.0 · works offline** for first installation.

The Windows installer is unsigned and Mac builds are not notarized. See the release notes for signing status and platform limitations.

Current installers are GitHub Release assets. The 0.1.7 binaries committed under `installers/` are historical; the `Build Setup Installer` workflow publishes Releases and does not update those repository copies.
