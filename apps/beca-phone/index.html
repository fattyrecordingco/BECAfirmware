Wi-Fi & phone hotspot

Wi-Fi MAC: Connect BECA to view

Use this address for manual home-router registration. It is BECA’s Wi-Fi address, separate from its setup access point and Bluetooth.

Connect BECA to view its network.

Connect Android USB to save here, or use BECA’s Wi-Fi setup page.

  1. For a hotspot, turn it on in your phone’s system settings. Choose 2.4 GHz on Android; on iPhone enable Maximise Compatibility when available.
  2. On Android, connect BECA by USB, enter the hotspot name and password above, then save. Home Wi-Fi uses the same form. BECA tests the connection before saving.
  3. On iPhone/iPad or without USB, join BECA’s setup Wi-Fi and open BECA Wi-Fi settings. If this phone cannot run a hotspot while joined to BECA, use a second device for setup while this phone hosts the hotspot.

Keep BECA powered and the hotspot enabled. After saving, reconnect the app; Wi-Fi controls use BECA’s new IP address from the router/hotspot client list. Some phones isolate hotspot clients; Android USB control remains available.

Connect directly on iPhone, iPad or Mac

BECA without a computer

Power BECA from a charger or power bank. Join its setup Wi-Fi, then open its Wi-Fi controller in Safari. If BECA has joined your router, open its current local IP address instead. This controller changes BECA’s settings and AUX sound directly.

For live sound in a native music app, choose BLE MIDI output on BECA, open that app’s Bluetooth MIDI panel and connect BECA BLE-MIDI. On Mac, use Audio MIDI Setup → MIDI Studio → Bluetooth. Pair through the MIDI panel.

The BECA Apple app combines these direct Wi-Fi controls with native MIDI and the BECA synth. It requires installation of the native app; installing this web page on the Home Screen does not add MIDI access. For browser sound over Wi-Fi, open BECA’s /play/ instrument, then Connect Wi-Fi and Listen.

Allow Local Network and Bluetooth when prompted. Keep the app visible while playing. If the setup network reports no internet, stay connected and open Safari manually.

Connection help

Use current Chrome or Edge, unlock the phone, connect without a USB hub, and make sure USB/OTG host mode is enabled in Android settings if your phone provides that option.

Link an iPad or tablet through a computer

Open this HTTPS web app on both devices on the same local network. Connect BECA by USB in Chrome on the computer. Keep both pages open and the computer awake. No native app is required.

  1. On the computer, create a code and copy it to the tablet.
  2. On the tablet, paste the computer code below and choose Join. Copy its reply back to the computer.
  3. On the computer, paste the tablet reply and choose Finish. Then tap Listen on the tablet.

Codes link one tablet and grant control of BECA. Share them only with your own device. Guest Wi-Fi or isolated networks may block the link.
