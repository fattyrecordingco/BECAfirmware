# BECA Bundled Driver Resources

Place redistributable vendor driver installers here before building signed release installers.

Expected Windows filenames:
- `windows/CH341SER.EXE` for WCH CH340/CH341 USB serial adapters
- `windows/CP210xVCPInstaller_x64.exe` for Silicon Labs CP210x USB serial adapters

Do not add vendor driver installers unless redistribution is allowed by the vendor license. If redistribution is not allowed, keep this folder to documentation only and use the official links in `docs/user/READ_BEFORE_FIRST_LAUNCH.md`.
