# Setup Installer Bundles

This folder is legacy. Download app 0.2.0 with included firmware 1.1.0 from the [official release](https://github.com/fattyrecordingco/BECAfirmware/releases/tag/setup-v0.2.0), or use the [download table](../../../README.md#download-beca-020).

The `Build Setup Installer` workflow publishes installers, firmware, manuals and checksums as GitHub Release assets after every platform build passes. It does not sync binaries into this folder or the historical top-level `installers/` folder.
