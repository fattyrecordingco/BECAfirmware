# Ableton Rack Notes

An `.adg` rack can be created from this template flow:

1. Create a new MIDI track.
2. Place `BECA Control.amxd` first in the chain.
3. Add any stock instrument after it (for quick testing, `Analog` or `Wavetable`).
4. Save the track as an Instrument Rack preset named `BECA Ableton Rack.adg`.
5. Map macros to key controls (`bpm`, `scale`, `root`, `preset`, `sens`).

This repo keeps the M4L source/device; rack export is user-specific because Ableton writes binary preset metadata tied to local Live/pack content.
